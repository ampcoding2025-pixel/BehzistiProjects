# AI Support & Ticketing Bot — Vendor Evaluation Pack

Printable interview and scoring materials for evaluating AI support/ticketing vendors.

## Files

| File | Use |
|------|-----|
| `01-Interview-Checklist.md` | Readable Markdown checklist (edit in Cursor / Word / Notion) |
| `02-Scorecard-Printable.html` | Printable scoring sheet + calculation worksheet |
| `03-Interview-Checklist-Printable.html` | Printable full interview question sheets |

## How to print

1. Open either HTML file in Chrome / Edge.
2. Click **Print this scorecard** / **Print checklist**, or press `Ctrl+P`.
3. Optional: choose **Save as PDF** as the printer to keep a PDF copy.
4. Print one set per vendor.

## Suggested meeting flow

1. Print **03** (checklist) for note-taking during the interview.
2. After the meeting, fill **02** (scorecard) and compute the weighted score.
3. Keep **01** as the editable digital master copy.

## Decision bands

- **80+** Strong candidate → proceed to PoC
- **65–79** Conditional fit → mitigate gaps in writing
- **50–64** Weak fit → continue only if no better option
- **&lt;50** Not recommended
- Any unanswered **Critical** question → **Hold**
